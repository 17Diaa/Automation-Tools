Scheduler

          
After each run the app waits a random delay (default 15–60 min + extra jitter) so posts are not on a fixed clock. Override with env UPLOAD_RANDOM_MIN_MINUTES, UPLOAD_RANDOM_MAX_MINUTES, UPLOAD_RANDOM_JITTER_SECONDS. Vercel cron should run every 15 min — /api/cron only uploads when the next random slot is due.
