Scheduler

          

            Vercel: žalias mygtukas Įkelti dabar iškart kelia į TikTok (vienas ciklas, kaip cron).
            Foninis scheduler čia neįmanomas — automatiniams intervalams naudokite Vercel Cron → /api/cron ir CRON_SECRET.
          

          
After each run the app waits a random delay (15–90 min + jitter) so posts look natural. Daily limit: 15 uploads/day (env UPLOAD_DAILY_LIMIT). Override intervals with UPLOAD_RANDOM_MIN_MINUTES, UPLOAD_RANDOM_MAX_MINUTES. Vercel cron runs every 15 min — /api/cron only uploads when the next random slot is due and daily limit is not reached.
